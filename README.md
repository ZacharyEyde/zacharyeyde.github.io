Source for Zachary Eyde's research website: https://zacharyeyde.github.io

and deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

The theme's own guides are [QUICKSTART.md](QUICKSTART.md) and [CUSTOMIZE.md](CUSTOMIZE.md).
